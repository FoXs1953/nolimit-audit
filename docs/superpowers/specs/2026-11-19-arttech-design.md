# NoLimit · Дневник. План ArtTech

**Статус:** дизайн для согласования. Команда выбрала живую интерактивную открытку и прежний мобильный стиль. Рабочее имя «NoLimit · Дневник», пять демонстрационных дней, локальное хранение и настройки ниже предложены для первой версии. Документ описывает будущий продукт.

## Что должен почувствовать человек

В обед человек замечает, что мокрая остановка пахнет тополем, и записывает одну фразу. Вечером добавляет фотографию запотевшего окна и песню из наушников. Через месяц он находит день по слову «остановка», касается картинки и снова слышит музыку. Узнавание этой конкретной детали — цель дневника. Основная аудитория — люди, которые уже снимают на телефон и сохраняют музыку, но редко садятся за длинную дневниковую запись.

## Задание и границы первой версии

Основание — кейс **ArtTech · Make the Invisible Visible** в кабинете GENESIS.EXE. Онлайн-этап 19–22 ноября 2026 года. Сдача до **22 ноября, 23:59 по Астане**. Формат — команда из 2–4 человек. Одна папка на день, короткое осмысленное название в 3–7 слов, текст, минимум одно фото и песня. Оформление строится по всем трём входам. В архиве можно снова открыть день и услышать песню либо открыть её у музыкального сервиса. В демонстрации минимум три настроения. Организаторам нужны 3–7 примеров. Озвучка — дополнительная функция. ## Выбранный подход

| Вариант | Что делает человек | Что определило выбор |
| --- | --- | --- |
| **Живая открытка** | Касанием оживляет обложку, листает свои фото под музыку и читает одну точную фразу. | Выбрана пользователем. Один кадр уже работает, доступен просмотр без звука, все действия помещаются под большой палец. |
| Фотокнига | Читает текст и перелистывает развороты. | Удобна для длинной записи. Для дня с одним снимком и важной песней выразительность приходится добирать дополнительными разворотами. |

## Экраны и действия

Внизу телефона три пункта — **Сегодня, Архив, Настройки**. На ноутбуке те же разделы слева, в редакторе форма и предпросмотр стоят рядом. Основа из текущего сайта — поведение нижнего меню, плавное нажатие кнопок, закрытие панелей, история браузера и управление фокусом. Каждый старый публичный маршрут получит переход к началу дневника. Предыдущий релиз сохраняется в Git для отката.

| Экран | Кнопка или действие | Результат и граничный случай |
| --- | --- | --- |
| Сегодня | **Поймать момент** | Открывается короткая заметка с текущим местным временем. **Добавить в день** помещает текст в сегодняшний черновик. При повторном открытии можно добавить ещё одну деталь. Рядом доступен обычный ввод с клавиатуры. |
| Сегодня | **Записать день / Продолжить** | Открывается редактор выбранной даты. Если за эту дату уже есть папка, открывается её редактирование. Пользователь видит последнюю сохранённую версию. |
| Сегодня | **Посмотреть пример** | Открывается отдельная демо-коллекция. **Попробовать на копии** создаёт редактируемый личный черновик с явным указанием источника материалов. |
| Редактор | **Дата, Текст дня, Выбрать фразу** | Можно дописать вчерашний день, вернуть фразу из быстрой заметки, выбрать до одного предложения для подписи. Полный текст сохраняется независимо от длины подписи. Переход назад возвращает к черновику. |
| Фото | **Добавить фото, Сделать обложкой, Левее, Правее, Убрать** | Выбор из системной медиатеки. Первая фотография становится обложкой, кнопки меняют порядок без перетаскивания. При удалении последнего фото текст остаётся. Отмена системного выбора возвращает туда же. |
| Музыка | **Добавить ссылку / Выбрать файл**, затем **Послушать / Пауза, Заменить** | Файл воспроизводится после нажатия. Для ссылки — название песни, выбор её характера и доступная кнопка **Открыть песню**. При недоступности сервиса открытку можно листать, а ссылку заменить. Выбор нового трека пересчитывает ритм. |
| Предпросмотр | **Собрать открытку, Почему так?, Настроить, Сохранить день** | Открытка строится из введённых данных. Можно поправить название, обложку, трактовку настроения и ритм. Отмена правок возвращает прежний вариант. Если чего-то не хватает, прямо под полем появляется пояснение и фокус переходит к нему. |
| Открытка | **Оживить / Пауза, Предыдущее фото, Следующее фото, Звук, Прочитать запись** | Первый тап запускает движение и собственное или демо-аудио. Доступны обычные стрелки и жест. У одного кадра остаётся мягкое движение, переключатели кадров скрыты. Внешняя песня открывается отдельно по явному нажатию. Уход с экрана останавливает воспроизведение. |
| Архив | **Поиск, Месяц, Сбросить, Открыть день** | Поиск по названию, дате и словам записи. Папка содержит текст, фото, песню и готовую открытку. При пустом архиве предлагается записать первый день или открыть примеры. При пустом поиске показывается сброс фильтра. |
| Папка дня | **Изменить, Экспортировать день, Удалить** | Изменения сохраняются поверх того же дня. Экспорт даёт файл для личного хранения. Перед удалением видны дата и название, после него доступна отмена. |
| Настройки | **Уменьшить движение, Скачать копию, Восстановить из файла** | Движение учитывает системную настройку. Импорт показывает количество дней и конфликты до записи. При ошибке у прежней коллекции сохраняется целостность. |

Незавершённый день можно закрыть в любой момент. Черновику достаточно одного поля. Завершить день можно после добавления текста, декодируемого фото и музыки. Быстрые двойные нажатия создают ровно одну папку. Все сообщения об ошибках называют действие, которым человек может продолжить.

## Как день получает свой облик

Постоянная часть — вертикальное окно 4:5, поля, дата в верхнем углу, название одинакового кегля и короткая подпись. В интерфейсе — системный шрифт телефона и привычные кнопки, внутри карточки — спокойная антиква с кириллицей. Круглый контрол воспроизведения расположен под изображением. Важные слова и кнопки получают контрастную подложку на любом фото.

| Вход | Наблюдаемый признак | Что он меняет | Возможность поправить |
| --- | --- | --- | --- |
| Текст | Конкретные существительные, место, действие, время суток, слова темпа и контекст отрицания. | Смысловое название 3–7 слов, подпись, акценты в композиции. При двух состояниях начало и конец текста могут задать переход между кадрами. | Выбрать фразу, предложить другое название, изменить трактовку. По умолчанию сохраняются слова автора, факты и чувства от себя система не дописывает. |
| Фото | Доминирующие цвета после уменьшения, яркость, контраст, ориентация, порядок и число кадров. | Цвет бумаги, плотность теней, цвет акцента, ритм пауз между фотографиями. Цвета глаз и кожи не используются для выводов о настроении. | Сменить обложку, точку кадрирования или порядок, просмотреть полный оригинал. |
| Аудиофайл | Энергия по коротким окнам и выраженность атак в ограниченном фрагменте. При устойчивом пульсе оцениваем темп. | Длительность удержания кадра, мягкость перехода, размеры пауз. Паузы и диапазоны ограничены для комфорта. | При тихой записи или ненадёжной оценке включается ручной выбор характера. |
| Ссылка на песню | Описание самим автором дня: спокойная / ровная / энергичная, при желании жанр или короткий комментарий. | Тот же механизм движения меняет темп и амплитуду. Кнопка в объяснении указывает, откуда взялся признак. | Изменить характер, перейти к песне в сервисе. Так работает и ссылка, для которой сервис не предоставляет звук. |

Пример четырёх художественных решений. Для прогулки после дождя — слои и мягкие границы как в акварельной лессировке, отблеск берём из фото. Для ночной репетиции — короткий ритмический монтаж и диагональ из сценической фотографии. Для утреннего поезда — длинное горизонтальное движение как при съёмке из окна. Для шумного дня с тихим финалом — первый кадр плотнее, последний держится дольше. Выбор связан с текстом, светом и музыкой. Даже два спокойных дня будут различаться по фразе, цвету их конкретных фото и звучанию. У каждой открытки есть объяснение из трёх коротких строк.

## Дополнительные функции и приоритеты

1. **Поймать момент.** Одна строка с отметкой времени доступна с первого экрана. Например, три коротких заметки в течение дня вечером уже лежат в черновике. Эту функцию включаем в основную версию. Для диктовки на телефоне можно пользоваться системной клавиатурой.
2. **Сохранить именно это ощущение.** В предпросмотре автор выбирает фразу и может поправить трактовку («светлее», «спокойнее»). Учитываем поправку в сохранённой версии. Повторное открытие показывает тот же вид и порядок кадров.
3. **Найти по мелочи.** По запросу «какао» архив находит день даже тогда, когда в названии слова нет. Ищем и по коротким заметкам. Поиск работает на устройстве.
4. **Послушать запись.** Расширение при готовом ядре. Только доступные локальные синтезированные голоса с подходящим языком. Темп чтения и паузы зависят от записи. При запуске приглушаем музыку, после завершения восстанавливаем её. Если подходящего голоса нет, доступно чтение полного текста. Для локальной озвучки в папке сохраняем исходный текст и настройки чтения, а в демо с готовой звуковой дорожкой — сам файл и его происхождение. Не обещаем переносимость одного системного голоса между устройствами.
5. **Момент с запястья.** Отдельный эксперимент после основного релиза. В Court все 12 присяжных проголосовали против включения нативных часов в обязательную сдачу. Замысел — надиктовать короткую фразу с локальным временем и подтвердить импорт в нужную дату. Для возврата к идее нужны проверка на паре реальных Apple Watch и iPhone, сравнение времени ввода той же фразы на прогулке и один готовый день, где зритель узнаёт сохранённую деталь. Техническая приёмка — три успешных переноса подряд, включая повтор и восстановление связи, с одной записью в верном дне. [Разбор и 12 голосов](2026-11-19-arttech-watch-verdict.md)

### Что хранится и кому доступно

Публичный сайт показывает приложение и вымышленные демонстрационные дни. Личный текст, фото, аудио и поиск обрабатываются на устройстве. Отправку закрытых записей на сервер, общую ленту и регистрацию в объём первой версии не включаем. Переход по музыкальной ссылке открывает выбранный сервис. Экспорт с оригиналами может содержать встроенные метаданные фотографий и предназначен для личного хранения. Демо-изображения очищаем от лишних метаданных. Для примеров используем собственные, специально созданные или разрешённые материалы, ведём список источников и лицензий.

Дата дня — выбранная местная календарная дата; время момента — абсолютное время плюс исходный часовой пояс. Отображение на устройстве в другом поясе не переносит уже собранные дни. Для каждой даты есть одна основная папка. «Поймать момент» и «Продолжить» ведут в её активный черновик. В архиве у такой даты видна кнопка «Другие версии» с числом сохранённых копий. Импорт, копия демо и смена даты при совпадении сохраняют отдельную версию; текущая основная имеет приоритет. Для пустой даты основной становится первая добавленная версия. Действие «Сделать основной» меняет выбор явно, обе версии сохраняются. Каждая вкладка редактирует конкретную редакцию; конфликт оставляет собственную версию в «Других версиях». Документ, открытый при миграции базы, получает предложение перечитать сохранённое состояние.

Полная резервная копия включает готовые дни, все автосохранённые черновики, быстрые заметки, незавершённые редакции, варианты и привязку основной папки. Перед экспортом завершаем транзакцию активного редактора. При сбое предлагаем повторить экспорт после сохранения и показываем, какая редакция доступна. Проверка переноса включает утреннюю заметку без фото, несохранённые в готовую открытку вечерние изменения и две версии одной даты.

Браузер может освободить место, пользователь может очистить данные, режим приватного просмотра обычно временный. Перед добавлением крупных файлов показываем доступное место, если браузер его сообщает, и предлагаем резервную копию. При превышении квоты уже сохранённые дни и текст черновика остаются доступны. Перед импортом проверяем формат, число/размер файлов и объём после распаковки. У ссылок сохраняем адрес и описание; скачивание музыки стороннего сервиса в архив не предусмотрено. На другом телефоне дневник восстанавливается из экспортированного файла.

## Как проверяем

| Проверка | Условие готовности |
| --- | --- |
| Основной путь | Человек с телефона вводит свой текст, прикрепляет минимум одно фото и музыку, собирает день и находит его в архиве после перезагрузки. Отдельно повторяем с файлом и со ссылкой. |
| Управление | Вручную и в Playwright проверяем каждую строку таблицы экранов, включая закрытие панели, системный возврат, двойное нажатие, отмену выбора медиа, возврат из плеера, последнюю фотографию и пустой поиск. |
| 3 входа → 3 эффекта | Для одной базы меняем по одному входу. В отчёте фиксируем подпись и композицию после замены текста, палитру после замены фото, длительность и характер перехода после замены песни. Повтор без изменения входа даёт тот же рецепт. |
| Надёжность | Перезапуск с черновиком после каждого шага; потеря сети; большой или испорченный файл; заполненное хранилище; две вкладки; миграция на новую версию. Ошибка не перезаписывает последнюю сохранённую редакцию. |
| Резервная копия | Экспорт → чистый профиль → импорт → одинаковый текст, байты личных медиа, порядок кадров и оформление. Для ссылки восстанавливаются адрес и характер песни. Повторный импорт без изменений не создаёт дублей. |
| Телефон и доступность | Ширины 320, 390, 768 и 1360 px; Safari на iPhone при наличии устройства и WebKit, Chrome на Android или его эмуляторе. Проверяем также экранную клавиатуру, крупный шрифт, VoiceOver/клавиатуру, экран 200%, контраст, статичный просмотр, управление жестами и кнопками. Публикуем, какие устройства фактически прошли тест. |
| Скорость | Для образца из трёх фото и собственного трека измеряем время до обложки и до готовности анализа на доступном телефоне. Цель для обложки после декодирования фото — до 2 секунд; во время длительной обработки можно продолжать редактировать. Ограничиваем число полноразмерных изображений в памяти. |
| Приёмка в интернете | Чистый браузер без аккаунта открывает тот же URL, пять примеров, инструкцию, файл для восстановления и ссылки на исходники. Запись одного тестового пользователя не появляется на устройстве другого. Для личного аудио работает повтор без сети после подготовки оболочки; для внешней песни доступна ссылка. |
