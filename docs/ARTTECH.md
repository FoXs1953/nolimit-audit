# День в трёх материалах

**NoLimit · Дневник** помогает сохранить, как ощущался день. Днём достаточно отметить одну деталь. Вечером человек добавляет текст, фотографии и песню. В дневнике появляется отдельная папка и живая открытка, которую можно снова открыть спустя месяц.

**Для кого.** Для тех, кто снимает на телефон и связывает воспоминания с музыкой. Начать можно с короткой заметки. После сохранения день находится по названию, дате или слову из текста.

**Что остаётся общим.** Светлая оболочка, синий главный экран, системная типографика, белое поле фотоотпечатка, дата и подпись. У каждого дня одинаковое управление. Движение, цвет полей, ракурс отпечатка и интервалы смены кадров выражают различия между историями.

| Материал | Как влияет |
| --- | --- |
| Текст | Локальные правила извлекают заголовок из слов записи и выбирают фразу для подписи. Ключевые слова помогают определить настроение. Автор может изменить каждое решение. |
| Фото | Цвет обложки определяет оттенок полей, а выбранная автором точка кадрирования сохраняет главный предмет в кадре. Очерёдность снимков задаёт последовательность сцен. |
| Музыка | У файла оцениваются энергия и выраженность ритма. При доступном темпе длительность кадра рассчитывается по числу долей. У внешней песни используется выбранный вручную характер. Внутри открытки можно посмотреть объяснение каждого решения. |

**Художественные приёмы.** Длинная экспозиция подсказывает медленное движение для тихой сцены. Плёночный отпечаток и мягкий подъём кадра сопровождают тёплые детали. Контактный лист даёт сдвиг и смену кадров для радостной истории. Ритмический монтаж задаёт короткий акцент для напряжённого дня. В основе — фотографические техники. Конкретный цвет всегда приходит из самой обложки.

**Прототип.** Все вычисления и личная медиатека находятся в браузере. Файлы проигрываются локально, ссылки ведут к музыкальному сервису. Демо использует собственные мелодии и фотографии с указанным происхождением. Автоматическое определение настроения — художественная подсказка, которую редактирует автор.
