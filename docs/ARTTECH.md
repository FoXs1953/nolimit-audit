# День в трёх материалах

**NoLimit · Дневник** помогает сохранить, как ощущался день. Днём достаточно отметить одну деталь. Вечером человек добавляет текст, фотографии и песню. В дневнике появляется отдельная папка и живая открытка, которую можно снова открыть спустя месяц.

**Для кого.** Для тех, кто снимает на телефон и связывает воспоминания с музыкой. Начать можно с короткой заметки. После сохранения день находится по названию, дате или слову из текста.

**Что остаётся общим.** Светлая оболочка, синий главный экран, системная типографика, белое поле фотоотпечатка, дата и подпись. У каждого дня одинаковое управление. Движение, цвет полей, ракурс отпечатка и интервалы смены кадров выражают различия между историями.

| Материал | Как влияет |
| --- | --- |
| Текст | Локальные правила извлекают заголовок из слов записи и выбирают фразу для подписи. Ключевые слова помогают определить настроение. Автор может изменить каждое решение. |
| Фото | Цвет обложки определяет оттенок полей, а выбранная автором точка кадрирования сохраняет главный предмет в кадре. Очерёдность снимков задаёт последовательность сцен. |
| Музыка | У файла оцениваются энергия и выраженность ритма. При доступном темпе длительность кадра рассчитывается по числу долей. Для YouTube и треков Spotify используется официальный плеер. Время воспроизведения связывает фотографии с песней. |

**Художественные приёмы.** Для тихой сцены ориентиром стала ночная фотография с длинной выдержкой, поэтому кадр медленно смещается. Для тёплых деталей взяли белые поля моментальной фотографии и мягкий подъём отпечатка. Радостные истории отсылают к контактным листам репортажной фотографии, где взгляд переходит с одного кадра на следующий. Для напряжённого дня взяли ритмический монтаж немого кино с короткими акцентами. Конкретный цвет всегда приходит из самой обложки.

**Прототип.** Все вычисления и личная медиатека находятся в браузере. Файлы проигрываются локально. Для воспроизведения по ссылке нужен доступ к музыкальному сервису. Демо использует собственные мелодии и фотографии с указанным происхождением. Автоматическое определение настроения — художественная подсказка, которую редактирует автор.
